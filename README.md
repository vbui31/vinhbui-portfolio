# Vinh Bui Portfolio

Modern recruiter-focused portfolio built with Next.js, TypeScript, Tailwind CSS, Framer Motion, and Three.js.

## Stack
- Next.js (App Router)
- React + TypeScript
- Tailwind CSS
- Framer Motion
- Three.js (@react-three/fiber, @react-three/drei)
- Shadcn-style reusable UI components

## Run locally
```bash
npm install
npm run dev
```

## Production
```bash
npm run build
npm run start
```
