🚀 How to Publish on GitHub Pages
1.	Create a GitHub Account — github.com
2.	Create a New Repository
o	“+” → New repository → name it portfolio → Public → Create repository.
3.	Upload Your Files
o	Add file → Upload files → drag all files from the ZIP.
o	Ensure index.html is at the top level (not inside another folder).
o	Commit changes.
4.	Enable GitHub Pages
o	Settings → Pages → Source: main + / (root) → Save.
o	Your site: https://your-username.github.io/portfolio/
🎉 Done!
